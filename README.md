Juego de Adivinar el Número Secreto

Pequeña aplicación de consola desarrollada en Python como parte de mi ruta de aprendizaje en programación. Su objetivo es desafiar al usuario a adivinar un número secreto generado al azar, validando las entradas numéricas para evitar errores de ejecución y guiándolo mediante pistas dinámicas.

Tecnologías utilizadas
* **Python 3.x** (Manejo de lógica, bucles `while`, bloques `try-except`, librería `random` y control de contadores).

Funcionalidades
* Generación automática de un número aleatorio entre 1 y 100.
* Sistema de pistas inteligentes en tiempo real ("Demasiado alto" / "Demasiado bajo").
* Validación robusta de datos de entrada (bloqueo de letras, ceros y números negativos).
* Contador oficial de intentos que registra únicamente los movimientos válidos.
* Formato de salida limpio y profesional simulando una aplicación de consola interactiva.
